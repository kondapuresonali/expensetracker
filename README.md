# Expense Tracker (Python CLI)

A simple **menu-driven Expense Tracker** built using Python.  
This is a beginner-level command-line project created to practice core programming concepts.

---

## 📌 Features
- Add expenses with category and description
- View all recorded expenses
- View total expenses
- Menu-based interaction in the terminal

---

## 🛠️ Technologies Used
- Python (Core concepts)

---

## 📚 Concepts Practiced
- Variables and data types  
- Lists and dictionaries  
- Conditional statements (`if-else`)  
- Loops (`while`)  
- User input handling  
- Basic program flow
